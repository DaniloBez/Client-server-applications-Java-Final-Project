# Tic-Tac-Toe

Багатокористувацька клієнт-серверна гра в "Хрестики-нулики" з системою матчмейкінгу, глобальним рейтингом (ELO) та адмініструванням. 
Проєкт використовує власні TCP-пакети для гри в реальному часі та HTTP (REST API) для реєстрації/авторизації та загальної статистики.

## Основні можливості

- **Авторизація та Реєстрація**: Захист паролів за допомогою BCrypt, JWT-токени для HTTP-запитів.
- **Рейтингова система (Elo)**: Перемоги та поразки впливають на рейтинг гравців. Доступна таблиця лідерів.
- **Глобальний Матчмейкінг**: Гравці стають у чергу та автоматично з'єднуються з вільним суперником.
- **Real-time гра**: Використання власного бінарного протоколу поверх TCP для мінімальної затримки та таймер на хід.
- **Панель Адміністратора**: Можливість переглядати логі сервера, історію матчів, статистику гравців та блокувати/розблоковувати користувачів.
- **UI Клієнт**: Сучасний графічний інтерфейс, написаний на JavaFX, що використовує CSS для стилізації.

## Технологічний стек

- **Мова**: Java 25
- **Клієнтський UI**: JavaFX 25
- **Мережа**: TCP (власний бінарний протокол) + HTTP (REST)
- **База даних**: PostgreSQL 17
- **Міграції БД**: Flyway
- **Шифрування**: BCrypt (паролі), кастомне AES-шифрування для TCP
- **Авторизація**: JWT (JSON Web Tokens)
- **Система збірки**: Gradle (багатомодульний монорепозиторій)
- **Контейнеризація**: Docker + Docker Compose
- **Тестування**: JUnit 5 + Testcontainers (інтеграційні тести з реальними контейнерами БД)
- **Якість коду**: Checkstyle (Google Java Style linter), CodeQL (SAST)

## Структура проєкту

- `shared/` - Спільний код (DTO, інтерфейси, константи)
- `server/` - Серверний додаток (обробка TCP/HTTP, матчі, черга, робота з БД, міграції)
- `client/` - Десктопний додаток із графічним інтерфейсом на JavaFX
- `config/checkstyle/` - Налаштування правил лінтера
- `.env` / `.env.example` - Конфіденційні дані та конфігурація середовища
- `Dockerfile` / `docker-compose*.yml` - Конфігурації для розгортання в Docker

## Запуск

### Запуск за допомогою Docker (Рекомендовано)
При зміні коду сервер автоматично перекомпілюється всередині контейнера.

1. **Prerequisites:** [Docker Desktop](https://www.docker.com/products/docker-desktop/)
2. **Налаштуйте змінні оточення:** Зробіть копію `.env.example` і назвіть її `.env`.
3. **Запустіть систему:**
```bash
docker compose up -d 
```

### Локальний запуск (Для розробки)
1. **Prerequisites:** [Docker Desktop](https://www.docker.com/products/docker-desktop/), [Java JDK 25](https://adoptium.net/).
2. **Налаштуйте змінні оточення:** Зробіть копію `.env.example` і назвіть її `.env`.
3. **Підніміть базу даних (PostgreSQL):** 
```bash
docker compose up postgres -d
```
4. **Запустіть Сервер та Клієнт** через вашу IDE або Gradle:
```bash
# Запуск сервера
./gradlew :server:run

# Запуск клієнта
./gradlew :client:run
```

## Чистота коду та Тестування

Проєкт дотримується **Google Java Style**. 
Виконуйте цю команду перед кожним комітом для перевірки форматування та запуску unit/integration тестів:

```bash

```
