# Tic-Tac-Toe
Багатокористувацька клієнт-серверна гра в "Хрестики-нулики" з системою матчмейкінгу, глобальним рейтингом (ELO) та адмініструванням. 
Проєкт використовує власні TCP-пакети для гри в реальному часі та HTTP для загальної статистики.

# Технологічний стек
 - Мова: Java 25.
 - Мережа: TCP (власний бінарний протокол) + HTTP.
 - База даних: PostgreSQL 17.
 - Система збірки: Gradle (багатомодульний монорепозиторій).
 - Контейнеризація: Docker + Docker Compose.
 - Якість коду: Checkstyle (linter), CodeQL (SAST).

# Структура проєкту
 - `shared-core/` - Спільний код (DTO, класи повідомлень, криптографія)
 - `server/` - Серверний додаток (обробка TCP-з'єднань, матчі, черга, БД)
 - `client/` - Десктопний додаток із графічним інтерфейсом (UI гри)
 - `config/checkstyle/` - Налаштування правил лінтера
 - `.env` - Конфіденційні дані та конфігурація хостів
 - `Dockerfile` - Конфігурація образу бекенду
 - `docker-compose.yml` - Оркестрація БД та Сервера
 - `docker-compose.dev.yml` - Оркестрація для розробки

# Запуск
## Запуск за допомогою Docker
При зміні коду сервер автоматично перекомпілюється всередині контейнера.

1. **Prerequisites:** [Docker Desktop](https://www.docker.com/products/docker-desktop/)
2. **Налаштуйте змінні оточення:** Створіть файл `.env` на основі `.env.example`.
3. **Запустіть систему:**
```bash
docker compose -f docker-compose.dev.yml up -d 
```

## Локальний запуск
1. **Prerequisites:** [Docker Desktop](https://www.docker.com/products/docker-desktop/), [Java JDK 25](https://adoptium.net/).
2. **Налаштуйте змінні оточення:** Створіть файл `.env` на основі `.env.example`.
3. **Підніміть базу даних:** 
```bash
docker compose up postgres -d
```

# Чистота коду
Google Java Style
Виконуйте цю команду перед кожним комітом для перевірки форматування та запуску тестів:
```bash
./gradlew check
```
Обов'язково встановіть плагін CheckStyle-IDEA у вашій IDE та підключіть файл `config/checkstyle/checkstyle.xml`, щоб бачити помилки під час написання коду.
